# ClaudePad UI 设计规范

**版本：** 2.2

**更新日期：** 2026-07-16

## 1. 设计方向

ClaudePad 使用克制的希卡科技主题：深蓝黑底色、低饱和青绿、古铜金边框和少量青色发光。像素地图负责营造探索感，数据面板仍需保持专业软件工具的密度、清晰度和可读性。

视觉原则：

- 主题统一，但不让装饰压过状态、会话和操作。
- 控件紧凑、对齐稳定、状态变化可预测。
- 动画用于解释状态迁移，不用于持续吸引注意力。
- 桌面与移动端保持相同的信息优先级。

## 3. 全局导航

页头分为品牌和右侧导航两组：

```text
◈ ClaudePad                         Ideas  Tips  [Sessions | Multi-Agent]
```

- 品牌始终链接到 Sessions。
- Ideas 与 Tips 是轻量工具入口，不得因工作区改版被移除。
- Sessions 与 Multi-Agent 使用一个紧凑的分段 Tab，活动项同时具有背景、边框和 `aria-current="page"`。
- 小屏下允许换行，但品牌、工具入口与工作区 Tab 的顺序不变。

共享样式优先维护在 `asserts/styles/header-nav.css`，页面只添加必要的主题变量。

## 4. Sessions

- 本地与远端环境使用对称区块，区块标题包含环境、配置和版本状态。
- 卡片主区域用于打开终端；`◈ 修复 Bug` 是独立的次操作，不能与卡片点击冲突。
- 会话名称单行省略，完整值可通过标题或详情获得。
- 状态颜色同时配合文字；动态 class 必须来自固定白名单。
- 空状态需要解释下一步，例如配置远端服务器或刷新会话。

## 5. Multi-Agent 地图

### 5.1 视口层级

从上到下依次为：地图 HUD、场景提示、可拖动大陆、居中的事件反馈、小地图。HUD 必须位于地图顶部，不遮挡中央塔与角色。

### 5.2 HUD

```text
WORLD 67DB · 2× 大陆 / 拖拽    [−] [100%] [+]  [◎ 中央塔] [⟳ 新大陆]
```

- 缩放值显示当前比例，点击恢复 100%。
- 中央塔按钮同时复位缩放与平移到设计默认值。
- 新大陆按钮生成新种子并提供简短状态反馈。
- 所有按钮至少 36×36 CSS 像素，并有可见焦点。

### 5.3 地图内容

- 中央希卡塔是视觉中心，按现有画布比例缩小，避免压过区域要塞。
- 不使用十字道路、广场或固定河流；地貌由种子生成并保持开放探索感。
- 四个区域通过颜色、植被和地貌区分，但共享同一低饱和主题。
- 角色、神兽、建筑和猪猪怪使用一致的等距像素插画语言。

### 5.4 相机与小地图

- 拖动地图时使用抓取光标；拖动阈值防止误触 Agent。
- 缩放以指针或视口中心为锚点，范围限制在 `55%–160%`。
- 小地图视窗框实时反映主相机，点击小地图定位。
- 相机变化不触发会话重新加载。

## 6. 状态与动效

- 页面入场：一次性，≤ 500ms。
- 加载与连接：只在请求未完成时运行；成功、失败、超时或离开页面立即停止。
- 事件：反馈居中显示，随后进入明确终态。
- 状态点可以低频脉冲；正文、按钮和终端底部不得无限闪烁。
- 在 `prefers-reduced-motion: reduce` 下移除循环、路径移动和大幅缩放。

## 7. 可访问性

- 所有可点击卡片支持 `Enter` 与 `Space`，内部按钮不触发父级操作。
- 焦点样式使用 `2px` 高对比轮廓并保留外边距。
- 地图提供描述性 `aria-label`；装饰素材标记 `aria-hidden="true"`。
- `aria-live` 仅用于连接结果、地图生成和事件阶段，不重复播报动画帧。
- 触控设备不依赖 hover 才能发现操作。

## 8. 响应式断点

- `≥ 1100px`：地图与侧栏并排，HUD 单行。
- `720–1099px`：面板可换行，HUD 分为状态和按钮两行。
- `< 720px`：单列布局，导航换行，地图保持可拖动，小地图缩小但不隐藏。

## 9. 发布检查

- 共享导航在五个页面名称、顺序和活动状态一致。
- Tips、Ideas、配置与版本入口均可见。
- Session ID 很长或含特殊字符时不破坏布局或脚本。
- 终端恢复提示不会重复或无限动画。
- README 截图使用演示数据，不包含用户名、主机名、IP、密钥或本地路径。
